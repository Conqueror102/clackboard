# Credits

Clackboard is built on the work of others:

- **[Hushboard](https://github.com/tekcify/hushboard)** by Tekcify and contributors (MIT). Clackboard started as a fork; the keyboard lock, tray panel, island and design system come from it.
- **Switch sounds** from **[Mechvibes](https://github.com/hainguyents13/mechvibes)** by Hải Nguyễn (MIT). The packs in `src-tauri/resources/packs/` are copied unchanged; the license is in `src-tauri/resources/packs/LICENSE-mechvibes.txt`. Clackboard reads the Mechvibes pack format (V1 and V2), so community packs can be added from the panel.
- **Icons**: Nucleo Glass (free set, Nucleo license), see `design-system/project/assets/IconsGlass/README.md`.
